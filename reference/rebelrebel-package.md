# rebelrebel: Fast Maps on 'MapLibre' for Marine Data

Interactive maps of parquet files and 'DuckDB' tables, drawn in the
browser by 'MapLibre GL JS': vessel tracks, survey stations, gridded
effort, depth, relief and contours. The data stay in 'DuckDB' and reach
the page as vector tiles, so a map of millions of rows stays fast and
its colours, filters and legend change in the page. A map is served from
R on the local machine, or written as a folder that opens from its
'index.html' with no R and no network but the base map's. Moved from the
R package 'ramb', whose map viewer it was.
